這一版重新整理了程式內部，讓製作投影片更穩定，並加入幾項新功能。

## 新增

- **查詢經文更方便**：只要一個輸入框，直接輸入 `約3:16-18`、`約翰福音 3:16,18`、`詩23`（整章），好幾段可以用「；」分開一次查詢。
- **書卷別名**：可以自行新增教會習慣的書卷縮寫（例如用「雅各」代表雅各書），週報和查詢都能使用。
- **製作完成時列出問題**：少數經文做不出來時，會在最後列出原因，方便回頭檢查週報。
- 證道主標題後面直接寫的經文，現在也會做成投影片。

## 改善

- 個別經文有問題時不再中斷整份投影片，其他部分會照常完成。
- 要存檔的投影片還開在 PowerPoint 裡時，會提示先關閉再製作。
- 製作過程中「製作」按鈕會暫時停用，避免重複製作。
- 切換畫面時，查詢畫面輸入的內容不會消失。
- 安裝後的程式名稱固定為 FaithSlide，升級時會直接取代舊版。
- 記錄檔改放在 `%APPDATA%\FaithSlide`，回報問題時更容易找到。

## 修正

- 用「各」代表雅各書時，投影片做不出來。
- 詩篇第 100、110、120…150 篇的篇數顯示錯誤（例如「一百一十零篇」）。
- 第十個以後的標題（例如 `10.`、`十一、`）會被拆成兩個。
- 中標題底下沒有經文，或主標題後面直接接經文時，整段投影片做不出來。
- 週報缺少讀經時，整份投影片做不出來。
- 讀經寫成「約翰一書三章1節，四章2節」這種格式時，書卷名稱判斷錯誤。
- 檢查更新時，版本號比較錯誤（例如把 1.10 當成比 1.9 舊）。
- 製作後的投影片檔案裡不再夾帶多餘的隱藏範本頁，檔案稍微變小。
