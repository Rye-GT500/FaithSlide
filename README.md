# FaithSlide 證道投影片小幫手

把教會週報（Word 檔）一鍵做成主日證道投影片，也可以快速查詢和合本經文。

- 自動抓取讀經經文與證道大綱裡引用的每一節經文
- 依大標題、中標題、小標題排好投影片順序
- 經文字數多時自動縮小字體，放得進一張投影片

---

## 下載與安裝

1. 到 [下載頁面](https://github.com/Rye-GT500/FaithSlide/releases) 下載最新的 `FaithSlide-Setup-版本.exe`。
2. 執行安裝檔，依畫面指示完成安裝。
   - 若出現「Windows 已保護您的電腦」，請點「其他資訊」→「仍要執行」。
3. 從開始選單或桌面捷徑開啟 FaithSlide。

> 查詢經文需要網路連線。
> 有新版本時，直接執行新的安裝檔即可，會自動取代舊版。

---

## 製作投影片

1. 開啟 FaithSlide，按「**選擇 Word**」選擇本週的週報。
2. 按「**選擇儲存**」，決定投影片要存在哪裡、檔名叫什麼。
3. 按「**製作**」（或按 Enter），等進度條跑完，出現「製作完成」即可。

投影片的順序是：

1. 讀經的每一節經文
2. 證道主標題
3. 每個大標題、中標題、小標題，後面接著它所引用的經文

如果有少數經文做不出來（例如節數寫錯），程式會照常完成其他部分，並在最後列出有問題的地方，方便您檢查週報。

---

## 週報要怎麼寫

週報中需要一個表格，表格最左邊一欄分別寫「**讀經**」和「**證道**」，內容寫在右邊一欄。

### 讀經

第一行寫經文出處，下面每一節以「[節數]」開頭：

```
約翰福音十五章1-5節
[1]我是真葡萄樹，我父是栽培的人。
[2]凡屬我不結果子的枝子，他就剪去……
```

讀經有好幾段時，有兩種寫法：

- **每段各寫一行出處**：寫完第一段的經文後，另起一行寫下一段出處（例如「士師記十八章」），再接著寫經文。
- **出處寫在同一行**：用「，」分開，例如「以弗所書二章10節，一章17-19節」，下面依序寫出所有經文。

讀經的書卷會當作這次證道的「**主經文**」：證道裡沒有寫書卷的經文，會自動使用這卷書。

### 證道

只有**粗體字**會被做成投影片。講員的職稱與姓名（例如「牧師」）會自動略過，可在[設定](#設定)中調整。

```
神翻轉生命                          ← 第一行：證道主標題
一、神翻轉生命：                     ← 大標題
1. 從死亡到生命：弗 2:1-3,5-6        ← 中標題
1) 認識恩典：2:4-5,8-10              ← 小標題（沒寫書卷，使用主經文的書卷）
2. 從敗壞到美好：弗 1:3 箴 5:3
```

| 項目 | 寫法 | 例子 |
|---|---|---|
| 大標題 | 中文數字＋「、」 | `一、神翻轉生命` |
| 中標題 | 數字＋「.」 | `1. 從死亡到生命` |
| 小標題 | 數字＋「)」 | `1) 認識恩典` |
| 經文 | 寫在標題後面 | `一、神翻轉生命：弗 2:1` |

### 經文的寫法

| 寫法 | 例子 |
|---|---|
| 書卷縮寫＋章:節 | `弗 2:8` |
| 一段範圍 | `弗 2:1-3` |
| 同一章好幾段，用逗號分開 | `弗 2:1-3,5-6` |
| 接著寫下一章 | `約 15:12-13,13:1-5` |
| 不同書卷，用空白或逗號分開 | `加 5:22-23，弗 5:9` |
| 沒寫書卷，使用主經文的書卷 | `2:4-5` |

注意事項：

- 書卷請用**縮寫**，見文末的[縮寫對照表](#書卷縮寫對照表)。
- 不支援跨章的範圍（例如 `約 3:16-4:2`），請拆成 `約 3:16-36,4:1-2`。
- 兩段沒寫書卷的經文之間，請用逗號分開（`2:4,3:1`），只用空白分開會被當成同一段。

## 查詢經文

按「**切換**」（或 F5）到查詢畫面，輸入經文後按 Enter：

| 輸入 | 說明 |
|---|---|
| `約3:16` | 查一節 |
| `約3:16-18` | 查一段 |
| `約翰福音 3:16,18` | 也可以寫全名；好幾節用逗號分開 |
| `詩23` | 查整章 |
| `約3:16；羅8:28` | 查好幾段，用「；」分開 |

## 設定

按視窗右上角的 **⚙**（齒輪）開啟設定，改完按「儲存」，馬上生效。

### 書卷別名

如果教會習慣的縮寫和本程式不同（例如用「雅各」代表雅各書），可以在這裡自行新增。新增後，週報和查詢都能使用這個寫法。

- 別名不能和其他書卷的名稱重複，也不能有數字、空白或標點符號。
- 只有一個字的別名，可能把標題裡的字誤認為書卷，新增時會再跟您確認。
- 按「還原預設」可以回到原本的設定。

### 講員

週報證道欄裡的講員職稱與姓名（例如「牧師」、講員的名字），不應該出現在投影片上。把它們加到這裡，製作時就會自動略過。

- 請輸入兩個字以上。只有一個字的話，標題裡所有相同的字都會被刪掉。
- 有新的講員時，記得把名字加進來。

## 常見問題

**出現「無法儲存 PPT，檔案可能正在 PowerPoint 中開啟」**
要存檔的投影片正在 PowerPoint 裡開著。請先關閉它，再按一次「製作」。

**完成時列出「本章沒有第 X 節」**
週報裡那段經文的節數超過了該章的範圍，請檢查週報的寫法。

**出現「找不到書卷」**
請確認縮寫是否在[縮寫對照表](#書卷縮寫對照表)中，或到[設定](#設定)的「書卷別名」新增您習慣的寫法。

**有些標題或經文沒有出現在投影片上**
請確認那些文字在 Word 中是**粗體**，並且標題的編號寫法符合上面的說明。

**投影片上出現講員的名字**
到[設定](#設定)的「講員」把名字加進去，再製作一次。

**查不到經文**
請確認電腦有連上網路。

**開啟程式時詢問是否更新**
有新版本可以下載。選「是」會開啟下載頁面。
